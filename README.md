# Gym EPS

Bibliothèque de gymnastique au sol pour les élèves de 4e : 6 familles d'éléments classés de A à D, animations en 3D (profil, 3/4, face, dessus, rotation libre, ralenti, décomposition), critères de réalisation, progressions par niveaux avec consignes, matériel et remédiations.

Site : https://gab1point0.github.io/gymeps/

Sources du contenu : fiche « Les familles de la gymnastique au sol » (critères de réalisation) et fiches de travail interactives de gymnastique de F. Demazeux (lycée Jean Rostand) pour les progressions. Les animations sont dessinées par le site (aucune vidéo reprise).
